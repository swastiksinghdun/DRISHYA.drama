# DRISHYA.drama
**This project is a creative exercise that will give an overview on the Dramatics Club of IIT Bhilai: Drishya.**


Among the student run Cultural Societies of IIT BHilai is Drishya, the acting club of IIT Bhilai. It happens to be one 
the the most active and popular clubs among the students. We aim to make that reach extend a step further with this
website.
